# Blockchain Nodes

Central workspace for blockchain node operations, deployment notes, and infrastructure tooling.

## Purpose

The repository is intended to keep repeatable operational knowledge for running and maintaining blockchain infrastructure across different networks.

## Scope

- Node deployment procedures
- Configuration references
- Operational scripts
- Maintenance and upgrade notes
- Monitoring and troubleshooting material

## Status

Infrastructure operations workspace. Individual network procedures should be treated according to the configuration and documentation present in the repository.
